# Merge Files for AI

A small VS Code extension. Add files and code snippets to a basket, then copy or save them as one text for AI chats.

## Why

I don't want to code with agentic tools. I just want an easy way to send my files to an AI chat, so this lets me pick files or code and merge them into one paste or one file.

## Usage

- Right-click files or folders in the Explorer: **Add to Merge Basket**
- Select code in an editor (folded blocks included): **Add Selection to Merge Basket**
- Open the **Merge Files** panel to review, remove items, then copy, save, or clear.
